Sync with GitHub

Your syllabus, progress, review queue, settings, and every quiz result are saved as files in a private GitHub repo. Install the extension on another computer, enter the same two values, and everything comes with you.

Create a fine-grained token: Repository access → Only select repositories → your data repo; Permissions → Contents: Read and write. It's stored only on this device.

Gemini

Writes a lesson for you each day, generates quizzes from it, and marks written answers. Get a free key at aistudio.google.com/apikey. On the free tier, Google may use what you send to improve its products. The key is stored only on this device.
