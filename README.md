# Português Primeiro (phone version)

A website version of the [Português Primeiro](https://github.com/KagazzIe/portugues-primeiro) lock page, for doing
the daily lesson and quizzes on a phone. It's built from the extension's code by `tools/build-web.mjs`; don't edit
these files directly.

It contains no study data or keys. On first use, open Settings and enter a GitHub repo, a token for it, and a Gemini
API key; they're stored only in this browser. Progress syncs through that repo, so finishing the day here keeps the
streak and unlocks Firefox wherever the extension is installed.
